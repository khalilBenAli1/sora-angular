# Artwork and font provenance

- `public/images/seasonal-plate-*.webp` are optimized versions of the original food photograph generated with the built-in ImageGen tool for this portfolio in November2026. It depicts an illustrative seasonal plate for the fictional Sora restaurant. The approved source is `output/frontend-portfolio-prompts/references/assets/dining.png` in the parent workspace; the app has no runtime dependency on that path.
- Two locally bundled type families: Instrument Serif and DM Sans, distributed by Fontsource under their respective SIL Open Font Licenses. Package license files remain in the locked dependencies; web fonts are bundled by Angular, without remote font requests.
- The Sora favicon and interface decoration are original code-native SVG/CSS/text. No private client artwork, logos, photographs, or datasets are included.
- MIT applies to original application code. It does not override third-party font licenses or establish exclusivity over generated imagery.

Exact approved image prompt is recorded in `docs/image-prompt.txt`.
